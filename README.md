<strong>📖 O Projekcie</strong> <br>
Parking Lot to aplikacja mobilna tworzona w ramach ćwiczeń z programowania aplikacji na system Android. Projekt powstaje w ramach przygotowań do egzaminu zawodowego INF.04 (Projektowanie, programowanie i testowanie aplikacji)

Celem projektu jest praktyczne wykorzystanie języka kotlin i projektowanie interfejsu w xml oraz rozwijanie umiejętności tworzenia aplikacji mobilnych
